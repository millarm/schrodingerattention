Required corrections, bounded to the accepted A2b2a contract:

1. **The mixture known-valid ratio is not a weighted-mass ratio.**  Per-map and
   per-stratum code correctly derives known-valid mass divided by valid mass, but
   line 69 then reports `0.8 * routine_ratio + 0.2 * challenge_ratio`.  The
   required mixture is
   `(0.8 * routine_known_mass + 0.2 * challenge_known_mass) /
   (0.8 * routine_valid_mass + 0.2 * challenge_valid_mass)`, with `None` only
   when that denominator is zero.  Add a literal fixture whose two strata have
   different valid masses and ratios; the current unequal-map test checks only
   counts and an unavailable coverage value, so it cannot detect either map
   weighting or this mixture error.

2. **Local probe arrays lose the frozen observation identities and required
   head summaries.**  Lines 94–107 flatten candidate, stratum, layer, head and
   row axes into anonymous lists.  Projected RMS is additionally computed after
   the combined output projection and has no head axis.  Return raw records or
   parallel IDs that retain bank/stratum/candidate, layer, head and row/CLS
   identity, and provide the specified per-head summaries.  For projected
   sublayer effects, isolate each head's contribution through the corresponding
   output-projection block before summarizing per head; a combined projection
   may remain as an additional aggregate.  Tests must assert identities and
   head-specific grouping, not only flattened lengths.

3. **Zero reference RMS must be NA, not a clamped numerical ratio.**  Lines
   105–107 clamp zero denominators to `1e-30`, producing a finite but meaningless
   relative effect.  Emit explicit `None`/NA for each zero-denominator sample and
   make summaries ignore NA while reporting availability/counts.  Add literal
   zero-reference AV and projected-output fixtures.  The existing NA test covers
   route coverage only and does not exercise the probe requirement.

4. **Applicability and local/full-path fidelity are not represented honestly.**
   The softmax wrapper fabricates zero Hermitian/unitary/row diagnostics and
   labels its full-policy TV values as `all_rows_tv` and `cls_tv` (lines 118–128),
   although local SA mechanism quantities are not applicable.  Return explicit
   applicability plus NA/absent local and numerical fields for softmax; retain
   only genuinely defined control-policy comparisons.  For SA, literally verify
   that the manually propagated normal logits match the ordinary model forward,
   while keeping local same-hidden-state dt0 fidelity and propagated full-path
   dt0 effects separate.  Tests should exercise nonzero evolution, prove those
   two paths are distinct, and assert the candidate/stratum IDs carried by the
   full-path arrays.  The current softmax-only same-score test and SA shape test
   do not establish this contract.
